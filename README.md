# Задание 1

### Текст задачи

**Задание 1. List**
Составить программу, которая переносит в конец непустого списка L его первый элемент.

### Алгоритм решения

1. **Проверка граничных условий:**
   * Проверить входной параметр `list` на равенство `null`. Если ссылка не инициализирована, вернуть пустой список `new List<object>()`.
   * Проверить свойство `Count`: если в списке 0 или 1 элемент, циклический сдвиг не требуется — вернуть текущий список.
2. **Сдвиг элементов:**
   * Зафиксировать значение первого элемента во временной переменной: `first = list[0]`.
   * Организовать цикл `for` по индексу $i$ от $0$ до $\text{list.Count} - 2$. На каждой итерации переписать значение следующего элемента в текущую позицию: `list[i] = list[i + 1]`.
   * Записать сохраненное значение `first` в конец списка по индексу `list.Count - 1`.
3. **Возврат результата:** вернуть модифицированный исходный список `list`.

Сложность алгоритма: по времени — $O(N)$, по дополнительной памяти — $O(1)$.

### Тестирование

Тестирование выполнено с помощью модульных тестов фреймворка xUnit (`UnitTest.cs`) и интерактивного консольного режима (`Program.cs`).

**Сценарии тестирования:**
1. `MoveToEnd_MultipleElements_FirstElementMovedToEnd` — список из 5 разнородных элементов: `["Первый", 2, true, "Третий", 4]` $\to$ `[2, true, "Третий", 4, "Первый"]`.
2. `MoveToEnd_SingleElement_ListRemainsUnchanged` — список из одного элемента: `[42]` $\to$ `[42]` (список не изменился).
3. `MoveToEnd_EmptyList_ReturnsEmptyList` — пустой список: `[]` $\to$ `[]`.
4. `MoveToEnd_NullList_ReturnsEmptyNonNullList` — передача `null` $\to$ пустой инициализированный список `[]`.

3. **Возврат результата:** вернуть модифицированный двусвязный список.

Есть перечень мебельных фабрик, продукция которых представлена в мебельном магазине. Известно, мебель каких фабрик приобреталась n покупателями. Определить для каждой фабрики, мебель каких из них приобреталась всеми покупателями, каких — некоторыми из покупателей, и каких — никем из покупателей.

### Алгоритм решения

1. **Валидация входных коллекций:** если каталог фабрик `factoryCatalog` или множество клиентов `allCustomers` пусты либо равны `null`, вывести диагностическое сообщение («Каталог фабрик пуст.» / «Список покупателей пуст.») и завершить работу метода.
2. **Итерация по фабрикам:** для каждой пары `(factory, catalog)`:
   * Сформировать список множеств `purchasesPerCustomer`, где для каждого покупателя из `allCustomers` формируется множество товаров текущей фабрики, реально входящих в её официальный каталог.

   * **Покупки некоторыми (`somePurchased`):** из множества `anyPurchased` исключить множество `allPurchased` с помощью `ExceptWith`.
   * **Никем не купленные товары (`nonePurchased`):** из полного ассортимента фабрики `catalog` исключить все купленные товары `anyPurchased` с помощью `ExceptWith`.
3. **Вывод результатов:** вывести полученные множества в консоль с проверкой на пустоту (вывод «нет», если множество пусто).

### Алгоритм решения

1. Проверить наличие файла по пути `filepath`. Если файл не найден, вывести сообщение об ошибке.

**Задание 5. Dictionary/SortedList**
В молочных магазинах города Х продается сметана с жирностью 15, 20 и 25 процентов. В городе X был проведен мониторинг цен на сметану. Напишите эффективную по времени работы и по используемой памяти программу, которая будет определять для каждого вида сметаны, сколько магазинов продают ее дешевле всего. На вход программе сначала подается число магазинов N. В каждой из следующих N строк находится информация в следующем формате:
`<Фирма> <Улица> <Жирность> <Цена>`
где `<Фирма>` – строка, состоящая не более, чем из 20 символов без пробелов, `<Улица>` – строка, состоящая не более, чем из 20 символов без пробелов, `<Жирность>` – одно из чисел – 15, 20 или 25, `<Цена>` – целое число в диапазоне от 2000 до 5000, обозначающее стоимость одного литра сметаны в копейках. `<Фирма>` и `<Улица>`, `<Улица>` и `<Жирность>`, а также `<Жирность>` и `<Цена>` разделены ровно одним пробелом. Пример входной строки:
`Перекресток Короленко 25 3200`
Программа должна выводить через пробел 3 числа – количество магазинов, продающих дешевле всего сметану с жирностью 15, 20 и 25 процентов. Если какой-то вид сметаны нигде не продавался, то следует вывести 0.
Пример выходных данных:
`12 10 0`

### Алгоритм решения

1. **Создание файла (`CreateSourCreamFile`):** записать количество строк в первую строку файла, затем построчно вывести записи магазинов.

   * Считать первую строку и распарсить число $N$.
   * В цикле прочитать $N$ строк, разделяя каждую по пробелам на составляющие: фирма, улица, жирность, цена.
   * Распарсить жирность `fat` и стоимость `price`:
     * Если `price < minPrices[fat]`: обновить `minPrices[fat] = price` и сбросить счетчик `counts[fat] = 1`.
     * Если `price == minPrices[fat]`: инкрементировать счетчик `counts[fat]++`.
   * Сформировать строку `"counts[15] counts[20] counts[25]"` и вывести её в консоль.

# Задача 6, 7

### Текст задачи

**Задание 6. Перегрузка операций**
Вычитание переменной типа Time (учесть, что возможен переход в предыдущие сутки). Результат должен быть типа Time.

**Задание 7. Перегрузка операций**
Унарные операции:
`++` добавление минуты к объекту типа Time.
`--` вычитание минуты из объекта типа Time.
Операции приведения типа:
`int` (неявная) – результатом является количество минут (время переводится в минуты);
`bool` (явная) – результатом является `true`, если часы и минуты не равны нулю, и `false` в противном случае.
Бинарные операции:
`< Time t1, Time t2` — время переводится в минуты, результатом является `true`, если количество минут в левом операнде меньше, чем количество минут в правом операнде, и `false` – в противном случае.
`> Time t1, Time t2` — время переводится в минуты, результатом является `true`, если количество минут в левом операнде больше, чем количество минут в правом операнде, и `false` – в противном случае.

### Алгоритм решения

1. **Инкапсуляция и валидация:** поля `_hours` и `_minutes` объявляются как `readonly`. В конструкторах выполняется валидация: $\text{hours} \in [0, 23]$, $\text{minutes} \in [0, 59]$. При парсинге строки выполняется разбиение по символу `:` с контролем формата.
2. **Вычитание времени (`Subtract` и оператор `-`):**
   * Перевести текущее время в абсолютные минуты: $M_1 = \text{\_hours} \times 60 + \text{\_minutes}$.
   * Перевести вычитаемое время в абсолютные минуты: $M_2 = \text{other.\_hours} \times 60 + \text{other.\_minutes}$.
   * Найти разность $\Delta M = M_1 - M_2$.
   * Если $\Delta M < 0$, произошел переход через полночь в предыдущие сутки: прибавить $24 \times 60 = 1440$ минут.
   * Сформировать новый объект `Time` со значениями часов $\Delta M / 60$ и минут $\Delta M \pmod{60}$.
3. **Операторы инкремента и декремента (`++`, `--`):**
   * Для `++`: прибавить 1 к общему числу минут и взять по модулю $1440$: $M_{\text{new}} = (M + 1) \pmod{1440}$.
   * Для `--`: вычесть 1 из общего числа минут; если результат отрицательный, прибавить $1440$.
4. **Приведение типов и сравнение:**
   * Неявный оператор `int` возвращает значение $\text{\_hours} \times 60 + \text{\_minutes}$.
   * Явный оператор `bool` возвращает `_hours != 0 && _minutes != 0`.
   * Операторы `<` и `>` сравнивают целые числа минут, возвращаемые оператором `int`.
